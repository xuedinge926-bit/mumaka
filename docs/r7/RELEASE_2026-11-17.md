# MUMAKA R7 · 正式六维风格权重（2026-11-17）

**最新正式评分权重来源：** [`data/r7/weights-2026-11-17.json`](../../data/r7/weights-2026-11-17.json)

## 生效范围与版本规则

本版本是 2026-11-17 用户明确要求正式发布的 **R7 新评分基准**，适用于数据中实际列出的 **44 套风格／模式配置**及其所含的首批 28 张经典专辑映射。并不声称历史目录中全部 565 个稳定风格 ID 均已核定，也不对已有发行数据、历史冻结评分、旧版公开页面进行隐式迁移。

权重继承顺序：

1. 2026-11-11 R6 完整 39 条研究记录（38 套可计算配置；原始朋克为历史空条目）。
2. 2026-11-15 用户确认的 20 风格研究基准对相同条目的后续修订，以及新增的风格配置。**布鲁斯摇滚 B/B/S/A 取代旧 B/C/S/A；原型朋克 A/B/S/A 填补旧空条目。**
3. 2026-11-15 后续讨论、2026-11-17 用户再次明确确认：新增 **政治嘻哈 Political Hip Hop = S/B/A/A**。Public Enemy 的 `It Takes a Nation of Millions to Hold Us Back` 使用政治嘻哈作为唯一主风格，旧映射的硬核嘻哈仍保留为独立风格，但**不再用于这张专辑**。
4. 用 R7 更新的歌词、作曲、表演、声音、愿景、语境定义解释新增评分，**未明确更改的权重一律继承**。

R7 特别注意：有组织的节奏性说唱人声创作在作曲维度举证；文字及声韵归歌词，实际 flow 的节奏诠释归表演，beat／采样织体及声音世界归声音。同一艺术证据不得重复计算。

## 算法与数据契约

- 歌曲：歌词／作曲／表演／声音／愿景／语境。
- 乐曲：素材／结构／表演／声音／愿景／语境。
- 前四维权重共 70%，愿景 15%，语境 15%；四维各有一个 S。
- 系数：S=1.90578024；A=1.642914；B=1.4042；C=1.19；D=1。
- `weight_i_percent = 70 * coefficient[grade_i] / SUM(first_four_coefficients)`。
- 总分（10 分制）：`2 * SUM(stars_i * weight_i_percent / 100)`。
- **计算不得使用展示两位百分数代替精确系数；仅最后呈现结果才按 ROUND_HALF_UP 舍入。** 完全同分的编辑位次须独立留证。
- 每张专辑只调用一个合规主二级风格，不按曲目时长混合；禁用未描述的笼统风格作退路。

## 发行数据与后续核算

正式数据文件包含完整 `records[]`、`albums_28[]`、`changes_from_r6[]`、`validation`。每个配置通过 `canonical_r7_key` 引用，例如 `r7:political-hip-hop|song`，但它**不是**对旧数据库 `genre_id` 的冒名。未能对应历史稳定 ID 的条目明确写 `id_resolution_status=requires_catalog_resolution`；它们在这份正式权重文件中具有可引用的独立 R7 键。

以后新的 R7 评分应以该 JSON 为权重的唯一发布来源，不直接调用 R6 静态表或 11 月 15 日已经被后续决议替换的映射。历史冻结评分、正式旧界面没有被本次提交自动覆盖。将此定义表接入线上评分程序／重新部署旧网页是**单独的工程步骤**，不可在完成前宣称线上界面已切换。
