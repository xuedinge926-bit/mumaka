# 中国乐曲独立初稿

42 个不同主艺人、42 张实际发行的唱片/完整录音版本。曲目包括民乐、古琴、钢琴、管弦、指弹、后摇、数学摇滚、电子与原声。不能由领域的技术复杂度决定星级。

低 2/2.5 档的证据最弱，均为低信心研究候选。尤其《彩虹山》《乱红》《Post Haze》《浮生素描》《Beautiful Energy》具有鲜明且受到肯定的艺术特点，现有发行资料不能证明整碟只达到低档；这些位置优先接受升档或替换建议，不能将本表误读为对经典的定案。表演低位也不能将职业钢琴家的技术水准简单降为低分，而应比较该具体录音的诠释比例、推进和多曲一致性。

版本重点：

- 《一意孤行》采用 1993 雨果目录，1991 创作、1992 目录和 2001 再版仍待实体核对；旧表 1987 不成立。
- 《1911》本次明确采用艺人 2021 十周年重混版，约 61 分钟，两个文件；2011 原四乐章版另外记录。
- 《角》为 2014 全长，2013 年为早期 EP；Bandcamp 展示的 2018 是再发行日期。
- 《天幻箫音》1996 有中国青年网与原 CD 目录相互支持；不能因听者 1998 年买到而写 1998。
- 《空山寂寂》采用可核的 2019 流通 CD（LY-A008、9787883208433），不冒充已锁定 2010 前后首版。
- 《Emperor / Fantasy》为 2014 DG/Mercury Classics 4810710，非后来 Warner 合作。
- 《Sound of China》2007 大陆、2008 国际与 2025 数字再版须区分，制作署名也涉及马久越，不能将录音制作都算赵聪演奏。
- 《Concertos for String Instruments》为陈怡 2018 BMOP/sound，非 Naxos 2016。

含少量和声、对话采样、非语义人声或片尾歌曲的器乐主导专辑，需核查所选版次的主体。曲目和时长不足以确定器乐占比时，不得自动批准。所有条目保留 `approved:false` 与“未做完整试听”。


### 最终发行身份补核

- 《Fantasia》采用DG具体发行页（2012年3月），《Concertos for String Instruments》改用BMOP/sound 1058原版说明书及UMKC院刊。
- 《古琴艺术》用两厅院实体馆藏及Qobuz目录核对Ocora 1990年九曲版；《记忆里的美好》用2006年3月28日五大具体发行页。
- 吕思清采用Marco Polo 8.225940，Naxos发行目录为1997年12月，Apple数字版权为1996年；不把它与上海交响/陈燮阳的另一版混用。年份按具体发行口径标注，暂不套用异版封面。
- 《国家宝藏》第三季流通目录有11轨，文案称十首主体；已区分，不再把11轨目录误写为严格10轨。
