## 选片与证据边界

中国歌曲只有万青出现两次，分别为 2010 年首专的歌词 4.5 与 2020 年《冀西南林路行》的愿景 5；其余三表各 42 位不同主艺人。没有用单张专辑反复占格。区域沿用发行活动及音乐文化场景口径，中国歌曲不限于普通话；《Antares》英语占主体，区域决定已在版次中说明。

后三表是完整独立研究初稿。公开目录用于确认发行和署名，厂牌介绍、作者访谈与专业评论用于定位主要艺术追求。半星仍是本项目的编辑研究判断，不能把他站总分直接换算为某一维，也没有宣称完成整碟复听。低档尤其需要证明局限持续存在于多数曲目；简约、商业、低预算、旧录音或小众本身都不能当负面证据。证据不足的候选可升档、移位或替换，不为补格制造贬低经典的“事实”。

每条均有格位 ID、作品 ID、规范主艺人 ID、艺人、具体发行年份、主风格、维度、等级、简短整碟理由、版次、状态、来源、证据、信心和待核点。前台只展示阅读所需内容，详细证据与冲突记录留在管理和完整备份里。

## 约束与维护

`npm run audit:references` 检查四表覆盖、稳定身份、七档七位主艺人、每表至多一位主艺人两次、专辑去重、年份、主风格、理由、来源地址、错名、封面出处、人工原始版及原图指纹。审计通过仅表示结构与元数据齐备，不能证明艺术定位正确。

管理工具保存时同样执行约束；未经审定的候选也不能绕过去重限制。完整备份包含人工底稿和本机历史选择，导入不能篡改同版本原文；新的人工归档只作为独立版本保存。

未来截图导入：先人工核对为同格式的 6×7 JSON，原始空格保留 `null`，设置新的 `manual-YYYY-MM-DD` 版本，再运行 `npm run import:manual-reference -- 转录.json 原始截图.png`。工具排除非 PNG、错误表头、错误档位及重复版本，独立归档后再审查接入差异；不声称具有自动 OCR 能力。

## 封面与验证记录

封面只采用已核对的官方发行展示缩略图，并提供回到发行页的链接和版权用途说明；未匹配到可信封面时继续显示缺图占位。`research-reference-covers.mjs` 只收集官方商品目录候选，不能改专辑、星级或人工选择，不能直接采用搜索首图。候选结果保存在 CI 的浏览器证据附件中，供版次、艺人与封面逐条复核。

本机已完成 301 项单元测试、18 项 Python 模型基准、标准构建、单文件构建和公开产物扫描。导入测试的 30 个无服务用例通过；3 个真实 HTTP 用例被本机禁止监听端口的权限限制阻断，预览服务同样报 `listen EPERM`。完整 `npm test`、`build`、Python 导入及 Playwright 验证交由现有 GitHub Actions 运行，最终结果以本次提交的 CI 为准。不会因本机无法启动服务而虚报浏览器验收通过。
