# 国际乐曲独立初稿

42 格使用 42 位不同主艺人、42 张不同唱片。保留古典、爵士、电子、氛围、后摇、器乐摇滚及原声等方法的相邻参照。旧表《Human After All》等明显以歌曲为主体的材料已移出。

所有半星属于编辑研究位置；低位不由名望、简单、预算、商业性或历史录音质量自动推出。资料与评论仅提供创作追求及局限线索，不能冒称逐曲完成复听。尤其器乐流行、极简和氛围作品，反复、稀疏或平顺可能就是有效的艺术选择；若不能证明在多数曲目中妨碍表达，低档必须上调或替换。

Gould《Goldberg Variations》按 1955 录音、1956 发行；Reich 按 ECM 1978 发行；《Giant Steps》按 1960 唱片发行。版本、主体器乐占比、低档局限及相邻差异分别写入各条 `edition/evidence/pending`。所有条目均为研究初稿，不将专业评论总分等同于本表的单维半星。
