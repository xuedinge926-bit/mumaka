# 新乐评主义 · Codex前全框架审计（V0.19-RC1）

**审计范围**：六维评分、十档等级、风格主库与中国市场索引、二级选择与跨家族合成、来源修正、文化定性／数值修正、N/A、声音/表演/作曲边界、发布与版本追溯。审计时间2026-10-29。

## 结论

**计算内核与索引架构具备进入Codex实现原型的条件；艺术评价系统不具备直接公开上线或宣称经过实证校准的条件。**

本次实质处理的是**数据入口、类型边界、版本冻结与可发表门禁**。没有对市场使用率作未经证实的判断，没有重排先前专辑排名。

## 数学与方法边界

- 六维：作词、作曲、表演、声音、愿景、语境；0.5到5星，步长0.5。固定愿景15%、语境15%，前四维合计70%。
- 总分：`Σ(星级 × 实际百分比权重) / 50`；精确有理数计算，最后按**half-up**取两位小数。
- 完整无歌词发行：Lyrics N/A（不是0星），只对适用的前三/四维中的动态维度归一；偶发器乐曲不使全碟作词N/A。
- 低分不因音乐简洁、制作年代、语言/文化身份而自动施加；高分不因流派名气、首创地位或题材宏大而自动授予。
- 来源修正是在词曲材料的**继承与新实现之间重分配关注**，不是自动奖励原创，也不能与“翻唱机械扣星”叠加。
- `publish_eligible`意为**用户填写的结构化前提齐备**，并非程序已验证其听过唱片、史料真实性或艺术标准达成。

## 尚未解决的设计决策（必须记为Codex TODO）

1. 33项中国市场索引真正的使用频率与外部认同，需多平台发行数据或至少跨独立来源的标签证据。
2. 是否保留“独立民谣”独立入口，需与“当代民谣”作可听性比较；不能按独立厂牌/自发行判定。
3. 西北民谣和西北民歌摇滚的候选归类：以跨音乐人、不同地域、全碟听感与资料验证决定是否值得新风格，不能预先认定。
4. 中文流行/中国风的档位实际权重需未来跨时代歌曲样本校准；不要按罗大佑与周杰伦预期名次倒调。
5. 文化修正档案0项已批准；来源比例12/16尚属待校准先验，未达正式实证等级。
6. 发布门禁中的“已核实”字段仍须审稿流程、责任人签名和审计日志支撑；程序无法判断用户是否假填。
