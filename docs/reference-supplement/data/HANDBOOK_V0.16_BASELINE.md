# 新乐评主义 · 评价手册 V0.16（创作来源修正与罗大佑试评）

> **状态：内部校准候选，不是已完成的实证听评标准。** V0.14 的语境时间解释规范、V0.13 的文化适配规则、534个二级风格权重与60条具体等级标准继续有效。本版把“翻唱的创作方式差异”正式表达为可审计的权重修正，但12/16个百分点的上限仍是测试性假设。

## A. 核心评价对象与版本优先级

1. 整张发行版为默认评价单位。六维仍为作词、作曲、表演、声音、愿景、语境；星级为0.5到5每半星一档，愿景与语境各固定15%。
2. **作词、作曲的星级评艺术质量；创作来源修正只调整两维相对重要性。** 来源与创作署名另外记录。已经用来源修正调整过权重，不得因为相同的“非新创作”事实又机械减星。
3. 新词曲可由专辑歌手本人、其他署名作者或委约词曲作者完成；“艺人不是词曲作者”绝不自动视为翻唱。
4. 对既有歌曲的重录要区分本人旧作重录、别人的既有作品翻唱、传统歌曲，以及旧词重新谱曲/旧曲新填词。只有实际涉及的艺术创造维度才考虑来源修正。
5. 翻唱主要艺术重心可能在重新诠释、声音、编配和选曲，但不能据此直接推断某项星级或某张专辑必然低于原创。
6. 先确定版本、核心风格、歌曲来源和是否启动修正，**然后再打星**；禁止根据目标总分反向选择权重。

## B. 创作来源修正（V0.16规则）

| 情况 | 作词Δ | 作曲Δ | 表演Δ | 声音Δ | Δ绝对值合计 | 适用要求 |
|---|---:|---:|---:|---:|---:|---|
| 新创作主导 | 0 | 0 | 0 | 0 | 0 | 默认；歌手非词曲作者也可属于本类 |
| 混合、轻度 | −1 | −1 | +1 | +1 | 4 | 既有歌曲有实质份额，但不是主导 |
| 混合、较多 | −2 | −2 | +2 | +2 | 8 | 旧作品占较大艺术份额且重新作曲有限 |
| 既有作品主导（标准） | −3 | −3 | +4 | +2 | 12 | 全碟主体依靠既有词曲，重心在当下诠释 |
| 既有作品主导（特别） | −4 | −4 | +5 | +3 | 16 | 需要逐曲证明极高的继承依赖、最小新词曲及足够的表演声音价值 |

**注意：绝对变动总量12指从旧维度转出6个百分点，再转入其他维度；不是直接把某维减去12个百分点。** 数学向量只是审核后的可选模板，不能自动套给全部翻唱。

### 准入与例外

- 按**词与曲分别**查看来源。只改歌词但大量保留原曲时，不能把作词和作曲一并照搬相同的负修正。深度重组和声/节奏/结构时，作曲负修正应减少或取消。
- 核心风格本身如果是爵士标准曲、传统民谣复兴、演唱型传统流行等，已有较高诠释权重，要先排除重复赋权；必要时取消来源修正。
- 不能按“唱片有几首翻唱”直接决定比例。曲目时长、艺术重心、实质改写和原曲来源均要记录。
- 每个修正向量必须零和；愿景15%、语境15%不变。来源L1≤16（标准≤12），文化L1≤4；二者毛额绝对变化合计≤16，避免通过方向互相抵消来藏掉超限修改。
- 本版低限：作词、作曲、表演、声音凡适用的最终权重至少5%。不满足时只能选择更温和的修正，不能将某维硬截到5%而不平衡其他维。
- **N/A流程与旧文化规则统一**：先对原始风格实施已批准文化修正；再把真正N/A的作词移除，将剩余三项动态原始权重按比例归一至70%；最后只在剩余适用维度间实施独立的来源修正。不得从已不存在的作词权重里第二次转出。
- 多风格并置先得到整张作品综合风格权重，来源修正仍针对整张专辑；作词/作曲仍只给整张作品一组星级。
- 不论有没有启动来源修正，**语境高分必须有本版对社会文化历史/音乐传统的具体艺术作用**；选用了旧时代经典、属于特定语言文化、不等于语境高分。

### 已知风险及发布标准

来源修正改变相对权重，不保证翻唱分数下降；当六维星级全为4时，无论权重如何移动都为8.00分。12与16尚未完成跨歌手实证听评校准，不得称作经验最优比例。正式发行评论需留下歌曲级词、曲来源、修改依据、审核时序和独立六维论据。

## C. 核心六维定义及十档等级（全部保留V0.14）

### 作词 · lyrics

评价音乐中语言文本的文学性及艺术表现，包括语言选择与组织、意象与修辞、叙事与结构、思想情感的文字实现，以及语言与音乐的关系。

**核心问题：**语言如何成为艺术表达？

| 星级 | 等级 | 可操作性标准 |
|---:|---|---|
| 0.5 | 极差 | 语言组织与表达基本失效，文本几乎不能形成可辨认的文学价值。 |
| 1.0 | 很差 | 大范围空泛、混乱或严重不合适的语言处理妨碍表达；仅零星词句有效。 |
| 1.5 | 较差 | 有少数可取的语言瞬间，但结构、意象或文字运用的问题持续压倒其优点。 |
| 2.0 | 欠佳 | 若干句法、意象或叙述处理有效，但套语、失衡或词曲脱节明显削弱整体。 |
| 2.5 | 一般 | 文本能完成基本表达，措辞和结构多为常规，文学创造的成效有限。 |
| 3.0 | 良好 | 语言运用准确有效，具有可以指明的文学表达优点，能与音乐形成良好关系。 |
| 3.5 | 优秀 | 有鲜明的意象、叙事、口语创造或文本节奏亮点，优点显著，但整体力度尚不持续。 |
| 4.0 | 卓越 | 形成成熟且持续的语言风格，叙事、意象或文字节奏富有表现力，词曲关系有效。 |
| 4.5 | 杰出 | 文学创造和语言控制极为出色，具有突出的表达密度、精准度或情感力量。 |
| 5.0 | 典范 | 实现顶级的语言艺术，形式与内容高度相互成就；不以词汇复杂或题材宏大为条件。 |

**边界：**文本本身及词曲相互作用归作词；演唱的具体诠释归表演；语言涉及的外部历史社会文化关系归语境。

### 作曲 · composition

评价音高、节奏、动机、声部关系、结构及其他音乐材料的创造、选择、组织与发展所形成的艺术成就，适用于不同音乐传统。

**核心问题：**音乐材料如何被创造与组织？

| 星级 | 等级 | 可操作性标准 |
|---:|---|---|
| 0.5 | 极差 | 音乐材料缺乏可辨认的有效组织，结构或发展根本失效。 |
| 1.0 | 很差 | 节奏、音高或其他材料大范围处理失当，音乐关系难以成立。 |
| 1.5 | 较差 | 个别材料或片段有效，但组织和发展明显失衡，整体缺乏说服力。 |
| 2.0 | 欠佳 | 有可取的构思，但材料连接、推进、重复或变化存在显著不足。 |
| 2.5 | 一般 | 音乐组织基本成立，多数材料较为惯常，结构与发展只有有限成就。 |
| 3.0 | 良好 | 材料选择和组织扎实，结构或发展具有明确可论证的音乐创作优点。 |
| 3.5 | 优秀 | 旋律、节奏、动机、结构或其他材料中有显著创作亮点，但整体发展未完全达到高水平。 |
| 4.0 | 卓越 | 音乐材料与结构关系成熟，变化、重复与推进持续展现出色的组织判断。 |
| 4.5 | 杰出 | 音乐构想极为鲜明，材料发展与整体结构高度有效，具有杰出的音乐表现力。 |
| 5.0 | 典范 | 音乐材料和组织实现顶级创造与表达；复杂、创新或旋律突出均非必要条件。 |

**边界：**音乐材料的组织归作曲；音乐实现时的表达性时值与具体诠释归表演；音色、空间与听觉质感归声音。

### 表演 · performance

评价音乐的具体执行、实现和诠释所形成的艺术价值，包括演唱、演奏、说唱、即兴、表达性时间与力度处理，以及可辨认的其他表演性实践。

**核心问题：**音乐如何被具体实现与诠释？

| 星级 | 等级 | 可操作性标准 |
|---:|---|---|
| 0.5 | 极差 | 具体执行与诠释几乎无法形成有效表达，或根本破坏音乐的实现。 |
| 1.0 | 很差 | 执行、律动或诠释大范围失效，仅有零星具有感染力的时刻。 |
| 1.5 | 较差 | 存在少数鲜活的表演瞬间，但控制、互动或表达失衡持续妨碍实现。 |
| 2.0 | 欠佳 | 某些诠释与律动有效，但具体执行或表现力存在明显的整体不足。 |
| 2.5 | 一般 | 音乐得到基本实现，处理较常规，表达个性、诠释或互动相对有限。 |
| 3.0 | 良好 | 具体诠释和执行有效，拥有可辨认的艺术个性、律动或表达优点。 |
| 3.5 | 优秀 | 技术控制、情感或节奏处理有显著优势，但尚未在整体上持续实现卓越表现。 |
| 4.0 | 卓越 | 形成成熟、鲜明且持续的诠释，演唱、演奏或其他表演实践富有感染力。 |
| 4.5 | 杰出 | 具体执行与表达极其鲜明、精准或自由，表现达到杰出高度而并非一定炫技。 |
| 5.0 | 典范 | 表演实现顶级诠释与表达力量；粗粝、传统或非实时的手段不构成自动扣分。 |

**边界：**设计好的节奏型归作曲；其具体表达性执行归表演；鼓机音色和混音归声音。

### 声音 · sound

评价音色、声部配置的听觉层面、声音纹理、空间、动态、录音及制作处理所创造的听觉美学与艺术实现。

**核心问题：**声音最终形成怎样的听觉世界？

| 星级 | 等级 | 可操作性标准 |
|---:|---|---|
| 0.5 | 极差 | 音色、层次或声音呈现几乎无法建立有效的听觉艺术关系。 |
| 1.0 | 很差 | 声音选择、组织或处理大范围损害听觉表达，仅零星细节有效。 |
| 1.5 | 较差 | 部分音色或空间处理可取，但整体质感、层次或处理判断问题突出。 |
| 2.0 | 欠佳 | 存在有效声音设计，但音色配置、空间或动态的明显缺陷妨碍整体表达。 |
| 2.5 | 一般 | 声音呈现基本成立，质感和组织较常规，尚缺少鲜明而有效的审美创造。 |
| 3.0 | 良好 | 音色、声音层次或空间处理形成清晰可论证的听觉艺术优点。 |
| 3.5 | 优秀 | 声音世界具有鲜明亮点和较强辨识度，但整体组织或持续性尚不足。 |
| 4.0 | 卓越 | 音色选择、空间、层次与质感持续构成成熟、鲜明的声音美学。 |
| 4.5 | 杰出 | 声音设计与听觉呈现极为杰出，各部分形成强烈而完整的艺术效果。 |
| 5.0 | 典范 | 实现顶级的声音艺术创造；高保真、昂贵设备与复杂制作均非必要条件。 |

**边界：**和声、对位、节奏结构等编配归作曲；音色组合、声音层次与空间归声音。

### 愿景 · vision

评价作品的艺术观念、审美方向、创造性与整体实现，以及与本张作品直接相关的音乐、文本、封面、影像和艺术形象如何共同构成独立、有辨识度的艺术世界。

**核心问题：**作品是否构成真正成立的整体艺术世界？

| 星级 | 等级 | 可操作性标准 |
|---:|---|---|
| 0.5 | 极差 | 艺术方向与整体实现几乎不能成立，作品元素缺乏可辨认的有效关系。 |
| 1.0 | 很差 | 概念、音乐与其他表达大范围脱节，整体艺术世界难以成立。 |
| 1.5 | 较差 | 出现少量有价值的整体构想，但大部分元素零散或实现严重不足。 |
| 2.0 | 欠佳 | 具有某些有效艺术想法，然而跨曲目或跨媒介关系松散，整体表达受损。 |
| 2.5 | 一般 | 作品形成基本的审美方向与整体框架，但艺术身份较为常规或实现有限。 |
| 3.0 | 良好 | 作品呈现清晰的艺术方向，主要元素之间形成可论证、有效的整体关系。 |
| 3.5 | 优秀 | 具有鲜明艺术身份与多处有效呼应，但整体观念或实现尚未持续达到高水平。 |
| 4.0 | 卓越 | 作品各要素形成成熟而鲜明的艺术整体；视觉若存在则与音乐有效相互成就。 |
| 4.5 | 杰出 | 艺术世界极具独立性与表现力，构想和实现接近顶级水准。 |
| 5.0 | 典范 | 实现顶级的整体艺术创造；无需宏大叙事、复杂视觉系统或高制作预算。 |

**边界：**具体歌词、音乐、声音成就分别入对应维度；愿景评价它们与视觉等材料共同形成的作品整体。

### 语境 · context

评价音乐作品凭借具体的文字、音乐、表演与整体组织，与历史、社会、文化环境及音乐传统形成的**可证实的艺术关系**，既包括创作与发行时的关系，也允许后来的接受与重新阐释**揭示作品本身所支持的文化意义**。不按后世声望、传播规模、发表年数计分。

**核心问题：**作品的具体艺术表达与文化历史世界形成了怎样的关系？后世阐释是否确实得到作品支持？

| 星级 | 等级 | 可操作性标准 |
|---:|---|---|
| 0.5 | 极差 | 作品明显尝试建立的文化／传统关系几乎完全失效，相关表达严重空洞、误置或无法从作品中成立；不因缺少显性社会题材判0.5。 |
| 1.0 | 很差 | 文化／传统材料处理持续严重误读或扁平化，少量有效联系不足以挽回整体表达失败。 |
| 1.5 | 较差 | 只有个别成立的文化联系，整体仍明显受刻板符号、附会或无效借用限制。 |
| 2.0 | 欠佳 | 与文化或传统有可定位的联系，但浅表、松散或发展不足，明显限制文化艺术表达。 |
| 2.5 | 一般 | 文化、历史或音乐传统联系能够辨认，表达基本成立，但独立艺术认识较常规、较有限；不因缺少接受史扣分。 |
| 3.0 | 良好 | 通过具体材料，与相关文化世界建立清楚且有效的艺术联系，形成可举证、有意义的认识。 |
| 3.5 | 优秀 | 对文化、社会或传统的回应有鲜明而独特的洞察，但深度、组织或持续性尚有限。 |
| 4.0 | 卓越 | 与文化、历史、社会或音乐传统形成深刻、成熟且持续的艺术关系，外部认识与内部实现相互支撑。 |
| 4.5 | 杰出 | 文化关系极其深刻独特，作品以充分的艺术实现提供杰出的理解空间；可以用当时证据或后来有根据的再阐释论证，但不要求已有长期接受史。 |
| 5.0 | 典范 | 相关文化关系的艺术认识、转化或表达达到可独立论证的顶级水准，具有尤其丰富、深远或可持续开展的阐释能力；不以经典地位、存世时间或宏大题材为必要条件或充分条件。 |

**边界：**文本本身归作词；作品内部整体世界归愿景；有作品证据的外部文化历史关系归语境；文化修正是评判公平性方法而不是语境或历史加分。

## D. 其他已经保留的计算原则

1. 核心二级风格优先；本家族有经审定General后备才可上退一级；真正跨家族且无主导风格才可逐曲确定风格并汇总权重。
2. 作词仅在整张作品确实无可评价语言文本时N/A；少量器乐曲不触发N/A；未评定与N/A不可混淆。
3. 表演和声音可能交叉，但必须论证演绎/执行与音色/空间的不同艺术贡献。
4. 文化适配审查适用于所有唱片；未经独立证据不能按地区、语种自动调用文化数值修正。
5. 语境包括创作时的具体文化历史关系、作品跨时代可阐释性和经证据支持的后世接受；经典地位、销量及媒体排行榜不直接加分。
6. 高星必须说明为何达到4.5/5而非低半档、是否具有全碟持续性、是否只引用作品声望；没有证据时只能标研究性候选。
7. 风格权重原始数据为V0.12的534条，尚未获得跨传统真实听评的实证证明。任何调整应保留版本与比较记录。

## E. 本版罗大佑专辑试评的验证边界

根据当前可用的非实时资料，暂对九张常见个人创作录音室专辑进行候选初评。2022年《安可曲》另列条件性再录制/发行样本；合作、原声、现场、精选不强行列入个人原创录音室主榜。因本环境无法实时核实完整发行目录，九张主榜也须核对官方发行信息。
罗大佑有为其他歌手写的歌曲后来由本人再唱，以及改编诗歌、方言歌曲等情形；不能因为词曲作者是罗大佑就将所有本专辑曲目自动认定为“在此首次发表”。
本轮没有完整取得全部原版音频、歌词文本和原始曲目署名；所有数值均为**研究性假设**，严禁转述为已经完成的正式全碟听评。

## F. 版本变更与冲突解决

- 本版对V0.15的主要替代：不再以“当前专辑新增词曲数量”作为给作词/作曲自动升降星的因素，改由核准的来源权重修正体现创作方式差别。仍要真实评价本版的艺术实现和改编质量。
- 本版对V0.14的最小变更：文化数值修正仍在作词N/A前实施，来源修正在N/A归一化之后实施，解决两种修正与N/A的顺序冲突。
- 原有六维定义与60条十档标准整体保留，语境时间意义继续使用V0.14修订版。
- `model-policy-v0.16.json` 与本手册为正式机器/人工规范；旧版文件仅供历史追溯，出现冲突优先采用本版明确修订条款。
