# 新乐评主义 V0.18 · 中国市场高频风格索引（保守试行版）

> **重要：这是一份“既有二级风格的中国市场使用索引”，不是额外的风格层级，也不是新评分尺度。** 保留V0.17的558条主库记录及其六维权重，**新增正式风格0条、改权重0项**。V0.18未采用先前扩充传统曲艺/民族器乐的V0.18草稿。
>
> **证据说明：当前无实时网络检索、平台目录抽样或原版唱片复听。** 索引名称按现有音乐批评和业界常见用法进行人工审慎筛选，**不能声称已用市场大数据证明这些名称的使用频率或认可度**。所有“高频”都是优先核验的编辑性判断。正式对外发布前必须完成独立使用证据与对照聆听验证。

## 1. 目标与边界

- 主要服务中国大陆及中文音乐语境的**流行、独立、摇滚、民谣、说唱、R&B、电子等唱片**；不追求中国所有传统音乐门类的覆盖。
- 采用**32个常用二级风格快捷入口**，另列12个已存在但未证实需进入快捷入口的观察候选；不为数量而新增类型。
- **语言、地区、创作身份和音乐风格分开记录**。国语、粤语、台语同音乐结构用同一基础权重。
- 中国风/古风合并为**中国风流行**一个音乐风格入口；“古风”保留为文化审美标签与别名，不再拥有独立六维权重。古风歌曲不符合可听中国风音乐要件时，归实际主风格。
- 既有全球通用类型一律复用原主库ID，不建立“中国版后摇滚”“华语House”等新权重。

## 2. 公开试用前的两道门

**第一道：分类可听性**。能否描述音乐语汇与排除条件，并在多个不同音乐人的唱片上重复判定？必须有全碟/曲目范围的可听证据；仅凭营销、古典歌词、艺术家身份或发行渠道不通过。

**第二道：实际使用认同**。至少汇集两类相互独立的、可回溯使用记录，例如流媒体编辑歌单/分类、发行商风格元数据、专业音乐评论/唱片目录、独立音乐社群的成熟稳定用语。需要区分“分类名称被提及”与“这是一种常被用作主风格的名称”。本轮没有完成这项验证。建议抽样至少200张横跨主流/独立、不同地区和年代的中国市场专辑；统计标签使用率、覆盖艺术家数、审稿人一致性，并记录平台与原始链接。**200张是拟议验证样本量，不是已经抽取的200张；任何阈值都不得伪称为已达成。**

32个名称不等于32套新配置：V0.17已存在的30个确立条目可直接引用旧权重；2个V0.17“provisional_chinese_focus”条目（另类流行、中国风流行）只能作为**有明确证据才启用的试验性权重**，绝不标为市场核验完成。

## 4. 分类时必须作出的边界判断

1. **流行 vs R&B vs Hip-hop**：优先看律动、声乐与和声、编曲/鼓组语言，不能以歌手名气或单首rap判断整张。R&B专辑中的中文演唱不产生“华语R&B”独立权重。
2. **流行 vs 中国风**：写古典词、用五声音阶、插入古筝都不能单独成立；需传统音乐的旋律/声腔/器乐编排语汇在全碟或核心曲目中持续参与音乐组织。中国风和古风同一个风格ID；具体美学仍可记录为非赋权标签。
3. **独立/另类/艺术流行**：独立发行不是Indie Pop，艺术观念强不是Art Pop，听感新奇不是Alternative Pop；要听到持续的歌曲结构、音色组织或编配差别。
4. **民谣/民谣流行/民谣摇滚**：木吉他不能自动判民谣；以叙事/原声为主体、以流行段落为主体或摇滚合奏为主体的权重不同。
5. **Shoegaze vs Dream Pop；Punk vs Post-punk；Blues Rock vs Pop Rock**：必须考察器乐组织、音色及全碟律动。避免仅因一首曲目改主风格。
6. **优先整个专辑一个主二级风格**；如果真实跨家族且没有单一主体，遵循V0.16原规则逐曲确定风格并合成一套整碟权重，**不新建并置三风格的新名称**，也不把每首歌星级平均来算专辑分数。

## 5. 来源修正、文化修正的使用顺序

| 步骤 | 行动 | 禁止事项 |
|---|---|---|
| 1 | 主二级风格：从主库或本索引定位既有ID，先记录选择理由和排除竞争类 | 不能因评分较高而回头换风格 |
| 2 | 语言与地方文化适配：先定性调整词韵、唱腔和传统等评价证据 | 不因语言/身份自动加文化分 |
| 3 | 创作来源审查：新作、旧歌翻唱、传统曲、旧作重录逐曲核证；适用V0.16候选来源修正 | 不因翻唱身份机械扣星，不对原作质量与来源重复计量 |
| 4 | 数值文化修正：默认0，确有额外且此前未被风格/来源覆盖的依据才考虑V0.13文化修正 | 不重复用相同文化证据，不能超限 |
| 5 | 六维独立打星并计算 | 不以音乐风格、经典地位或期望排名决定五星 |

- 来源修正绝对变化量标准12个百分点、特别情况上限16；文化修正最多4，二者合计绝对变化上限16（以V0.16规则为准）。
- 愿景与语境各15%不动；动态四维合计70%。
- 器乐作词N/A沿用V0.16正规化，不得为了主风格强行给歌词评级。风格所隐含的翻唱传统应先检查，避免双重来源调整。
- 上述修正幅度是模型候选，不是经过有代表性录音样本验证的“客观最优百分比”。

## 6. 旧试验条目的清理方式（不破坏历史数据）

原V0.17有24个临时新增中国相关二级类型。**本轮没有删除行、没有更改主库ID、没有修改任何基础权重**，而是为每条建立了索引决策：2条条件试用，若干合并/别名/转接，其余退出常用入口、保留历史扩展功能。参见 `V017_PROVISIONAL_24_DISPOSITIONS.csv`。

尤需注意：Mandopop（22/23/14/11）与Pop General（21/23/14/12）目前**不是相同权重**。从本版开始，新作品若只有普通流行的音乐特征，默认统一使用`genre:pop-general`；历史作品以前使用Mandopop计算的成绩**不会自动被静默覆盖**，需单独建立重算与审计记录。Cantopop及台语/客语亦同。

另一个例子：华语R&B流行旧试验ID拥有21/22/15/12的权重，而国际R&B现有21/19/16/14。两者差异确实可能影响分数；没有实听与市场依据，不可以仅因中文演唱而使用前者的单独百分比。本索引新分配优先`genre:contemporary-r-b`。这是结构透明化，不是宣布其中任何配置已被实证证伪。

## 7. 适用性与检验

- 全部32个核心入口都能解析到V0.17实际存在的二级风格ID，且直接复用旧六维基础百分比。
- 观察列表中的12项与核销旧试验条目的24项均提供逐项理由。
- 任何单张专辑的体裁、评分与市场地位均未重新主观改判；示例分类均标识“待音频与曲目核实”。
- 对于索引数据库的严谨程度，**代码可以验证ID、分类唯一性、权重和别名映射，但不能证明一个分类在现实市场上被高频使用。**
