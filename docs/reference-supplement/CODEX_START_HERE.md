# 新乐评主义 · V0.19-RC1 · Codex实施入口

**状态：规则与程序接口的候选冻结版（Release Candidate）；不是已经验证市场频率、完整唱片听评或艺术公允性的正式V1.0。**

## 本轮做了什么

1. 沿用V0.17的**558条全球风格记录与全部原有权重**，文件字节级不修改。558条中包含V0.17阶段的24个`provisional_chinese_focus`试验条目；不要把558理解为558个全部完成市场实证的正式类型。
2. 中国市场快捷索引从32改为**33项**；前32项保持原样，新增“校园民谣／校园民歌”作为**历史传统的入口别名**，实际关联到`genre:contemporary-folk`，不新增主库ID或六维权重。
3. “西北民谣”“西北民歌摇滚／西北摇滚”进地区民谣专项**审议表**；尚不是独立风格，也没有新权重。只讲西北方言的普通摇滚／民谣，按通用主风格评分，方言作为元数据。
4. 修正V0.18的一处旧决议冲突：不再整体否定“校园民谣”，但仍**否定“仅有校园题材就构成独立音乐风格”**。历史创作传统可作为检索入口，是否符合以音频和创作传统证据判断。
5. 为Codex提供可运行的Python参照实现，覆盖索引路由、跨家族权重混合、V0.16来源修正、V0.13文化修正边界、作词/极例表演N/A、六维星级、半入进位、**草稿与可发表资格检查**。
6. 完成全框架审计，将已可直接编码、需人工复核和必须冻结的规则分开，避免Codex按旧助手回答中的个别试评分自作主张。

## 本地运行

```bash
python -m unittest discover -s tests -v
python -c "from nmc_reference_v019 import resolve_index; print(resolve_index('cn-index:folk-rock'))"
```

无互联网、无第三方依赖。代码测试能够验证**结构和计算**，不能验证真实风格归属、公众认同、市场使用频率或艺术评分是否正确。

## 给Codex的单句任务

> 根据`CODEX_IMPLEMENTATION_SPEC.md`和`nmc_reference_v019.py`实现一套人工主导的整碟六维乐评工作台。以全球二级风格ID决定基础权重，以33项中国市场索引提高检索效率；按现有规则处理来源／文化修正及N/A。未取得必要证据的内容只保留草稿，不能发布正式评分。不要引入第三层混合风格，不要凭国籍／方言创建新权重，不要更改旧版成绩或声称市场频率已验证。

## 尚未解决、不能由Codex自行填补的研究问题

- 32项核心与新增校园民谣的**实际使用频率**尚无跨平台可追溯统计。
- 24项历史试验类型的逐项音乐学验证未完成；应在编辑管理界面提示“试验中”。
- 中国风流行／另类流行的专用权重仍是候选，不应与已验证权重混为一谈。
- 西北民谣／民歌摇滚是否可独立成类，需跨音乐人、跨唱片音频与独立使用记录；目前只建候选与人工审查流程。
- V0.16来源修正12/16个百分点属于工程假设，仍需跨流派、原创/翻唱配对听评校准；**不能机械当作翻唱减分**。
- V0.13文化数值修正当前**没有获批的实证权重档案**，默认全部为0。定性文化适配必须记录。
- 此前迪伦、罗大佑、许嵩、周杰伦的数字均是历史研究性试评分，不应当自动作为正式评分训练真值或校准答案。
