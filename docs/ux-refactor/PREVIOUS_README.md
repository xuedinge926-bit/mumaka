# 新乐评主义 · New Music Criticism

人工主导、本地优先的整碟六维评价工作台。React + TypeScript + Vite + Tailwind CSS，纯 TypeScript 评分引擎、IndexedDB 数据库、原生 SVG 玫瑰图。不需要服务器、账号、在线数据库或 API 密钥；不含预设专辑成绩或自动评分。

## 无需安装的本地版

单文件 HTML 版本把程序、样式、全部风格和评分规则打包在一起，与网页版使用同一评分引擎。可尝试将 `新乐评主义-直接打开.html` 下载到电脑后用 Chrome 或 Edge 打开，无需 Node.js；浏览器须允许本地网页执行脚本和访问存储。当前管理环境的浏览器禁止 `file://` 导航，本次未能直接验证双击文件的运行方式。若你的浏览器也限制本地 HTML，请使用下方已经验证的 Node.js 本地启动方式。

评价数据保存在浏览器 IndexedDB，**不会写回 HTML 文件本身**。请固定文件的存放位置和文件名，使用同一浏览器，并通过顶栏“导出全量备份”保留 JSON 文件。换电脑或换浏览器时，打开 HTML 后导入这份备份。

开发者可重现此版本：

```bash
npm run build:standalone
# 生成 standalone/新乐评主义.html
```

普通网站部署使用 `dist/` 文件夹；本地开发端口不等于可从公网打开的网址。当前云环境没有可用的公网入口，本次也未完成外部托管部署。

## 启动

需要 Node.js 22.12+（本次使用 24.19.0）和 npm。Python 3.10+ 用于原始参考测试与数据复核。

```bash
cd /workspace/mumaka
npm ci                 # 已有 package-lock.json；首次也可 npm install
npm run dev            # 默认端口 5173
```

构建与测试：

```bash
npm test
python3 -m unittest discover -s docs/reference-supplement/tests -v
npm run build
npm run preview        # 本地生产预览，默认端口 4173
npm run test:e2e        # 先 build；自动启动生产预览并用 Chromium 验证
```

浏览器测试默认使用 `/usr/bin/chromium`；其他机器可设置 `CHROMIUM_PATH`，或先用 Playwright 安装 Chromium 后调整配置。实际使用时请用固定的浏览器、域名、协议与端口；不同 origin 有独立的 IndexedDB，切换端口不会自动迁移记录。

## 使用流程

1. 新建评价，填写作品、音乐人、发行年份、确切版本、语言、厂牌及本地封面。
2. 添加曲目、时长、逐曲词曲作者/来源及核验依据。不能按歌手是否本人创作自动判断翻唱。
3. 选择 33 项中国市场入口或检索全部 558 项全球风格；记录全碟可听判据与相邻风格排除理由。校园民谣另需历史传统依据；中国风与另类流行需要条件证据。语言和地域不会改变权重。真正跨家族时可按曲目等份或可靠时长合成权重，整碟仍只评一组六维。
4. 填写文化定性适配，人工审核来源后选择冻结的五档来源修正，或使用有依据的独立来源向量。文化数值修正当前无获批档案，任何非零值只能研究，不能发表。
5. 各维独立选择 0.5–5 星并填写证据、反证和理由；4.5/5 星补充全碟支撑及为何不是低半星。未评价与 N/A 不同。作词 N/A 仅适用整张发行没有可评价语言文本，表演 N/A 仅适用经人工审批的极特殊情形。
6. 在审核页检查缺项，保存版本快照或人工批准发表。满足结构化条件不代表软件验证了史料真实性、全碟聆听或艺术判断。发表是本机归档状态，不会向互联网发布。
7. 导出评分卡 SVG/PNG、当前评价 JSON/CSV，或全量备份。

## 保存、备份和恢复

- 编辑后自动保存到 IndexedDB，也可点击“保存草稿”。浏览器拒绝存储、磁盘配额不足或图片格式无效时会显示错误。
- 点击顶栏“导出全量备份”保存整个作品库和历史快照 JSON；“导入全量备份”用于恢复。恢复是原子的：相同记录幂等跳过，冲突明确拒绝，不会静默覆盖。请先在空库或独立浏览器中恢复冲突备份，再手工决定保留版本。
- 当前评价 JSON 用于携带单条评价、模型来源及计算结果；**恢复入口接受全量备份格式**，不是单条评价 JSON。
- 已发表评价不可修改、删除或被新规则覆盖；需要重评时复制为新评价。历史快照保留当时专辑字段、六维、实际精确权重、分数、规则来源 SHA、审批责任人与时间。
- 本地存储不等于永久备份。清除网站数据、无痕窗口结束、浏览器清理或卸载都会导致丢失，请定期导出全量备份。
- 草稿自动保存保留最新内容；完整的前后版本需点击“保存版本快照”。本期未实现逐次按键的永久编辑审计日志。
- 生产构建包含离线应用缓存：首次在线打开、Service Worker 安装完成后可离线重载，继续评分和读取 IndexedDB。开发服务器模式不提供离线重载。首次访问仍需要载入应用；离线不提供外部音乐/史料。

## 模型来源与精度

原始四个附件保存在 `docs/model-source/`；补充 ZIP 的原始结构和文件内容保存在 `docs/reference-supplement/`，避免参考 Python 的 `tests/` 与浏览器测试混淆。它们是用户提供的模型规范，未当作高于用户要求的工具或系统指令。

- 模型：V0.19-RC1；全球权重：冻结 V0.17 CSV，共 558 条（24 条保留 `provisional_chinese_focus` 状态）。中国市场索引：33 入口引用 32 全球 ID，不建立第二套权重。
- 原始权重 SHA256：`afbdfdd0e0ff710a639808731b0d06b40fe244827049163d512751589c83bbf6`。
- 60 条等级标准按 V0.16 手册原文保留。未将历史研究专辑评分用作测试真值。
- `src/model/engine.ts` 独立于 React。采用 BigInt 有理数，最后一步 half-up 到两位；总分为 `Σ(星级 × 实际权重百分点) / 50`。显示用近似百分比不回流到计算。
- 顺序：基础权重 → 文化修正 → 移除 N/A 并归一动态维度到 70% → 来源修正。愿景、语境固定 15%。两类修正分别零和、仅整数百分点，L1 来源 ≤16、文化 ≤4、毛额合计 ≤16；最终适用动态维度 ≥5%。
- 若有未评价维度或非法配置，不生成总分。证据和审批不齐时可保留研究计算结果，不能正式发表。
- `src/data/provenance.json` 记录源文件哈希及参考核验状态；`scripts/extract_model.py` 可从原始 CSV/政策/手册重现浏览器数据（仅 Python 标准库）。测试校验全部数据与原文件一致。

## 明确边界

V0.19 是候选模型，不是已完成艺术实证校准的标准。33 项入口没有经平台统计证明市场使用频率；来源修正 12/16 个百分点仍是待实证先验。系统检查人工提供材料是否齐备，无法判断材料是否真实，不自动听音、爬取资料或根据艺术家声誉打星。多人审批、公开网站、在线发布、云端同步和用户注册不在本期范围内。

## 本次验收结果

- 原始 Python 参考测试：18 项通过，原文件未修改。
- TypeScript / 数据 / 存储 / SVG 组件测试：87 项通过，包括全部 9 条提供的黄金样例。
- 实际执行 Python 并与 TypeScript 对照：11,160 组（558 风格 × 5 来源档位 × 4 种 N/A 组合），4,382 组合法配置的精确权重与分数一致，6,778 组非法配置均被拒绝。
- Chromium 浏览器：4 个完整工作流通过，涵盖人工编辑与评分、保存刷新、离线重载、全库备份恢复、SVG/PNG 真实下载、人工发表、新评价不覆盖旧版、模拟旧模型分数不被重算、手机交互与无水平溢出，以及预览环境缺少 `crypto.randomUUID` / `crypto.subtle` 时的创建、保存与快照。
- TypeScript 类型检查及 Vite 生产构建通过。构建有静态只读风格资料所致的单包体积提示（约 607 KB / gzip 135 KB），不影响启动和离线工作。

上述结果只验证计算、结构和软件行为；技术验收中的虚构记录不作为作品评价或艺术真值，也不会内置到初始作品库。
