# V0.41 前端精简升级

承接 main 的 V0.40 发布（4eebe4acb9c8e4f73eb5a7015812da29fafbbba1）。实施前逐项比对本地树和远端 main：两者源代码树均为 f73a26b3769cb335768d0c2253c7affb2c9e047b。最近相关 PR 为 #1，已合并。本次保持评分引擎、六维定义、V0.38.1权重文件、稳定风格ID和历史数据库版本不变。

## 交付行为

- 品牌顺序「木马卡 MUMAKA」，中英副标题分排；全尺寸导航使用浮层和遮罩，支持外部点击、Esc、焦点约束及选择条目后收起。
- 首页仅有手动快速评分主入口，下方共享四类星级网格速览；取消当前首页的搜索、链接导入、研究与重复工作台入口。
- 单页手动信息、封面、歌曲／乐曲、地区、风格、星级、实时图卡和导出；评分草稿标签独立保存。半星悬停仅预览，点击或方向键才落值；维度说明可点击、悬停和键盘访问；逐维文字笔记收在可选区。
- 四类各42格，原V0.38.1与中国歌曲R3原文件保留。仅3个未分配、未审定R3格位采用独立补充候选；用户的审定内容优先，绝不自动批准。
- 标准一句、专辑／艺术家／年份、浏览用主风格和简明理由构成公开参考。主风格为宽泛浏览分类，不替代评分作品的风格选择，不参与权重计算。缺少可靠图片时占位；已有HTTPS图片懒加载及失败占位。
- 参考编辑工具位于「数据与工具」；按格保存、乐观冲突检查、已审定保护、人工审定人及完整核验确认。完整JSON备份保留这些内容，不改历史总分或冻结权重。
- 顶栏外观快捷入口及设置页：亮／暗／系统、陶土／松绿／靛蓝、卡片默认比例／配色／地区、默认展开说明、减少动画。兼容旧偏好键；系统偏好变化和重载生效。
- 数据备份、V0.19归档及V0.35工具集中到「数据与工具」。原服务兼容代码仍保留。

## 本地交付与发布

`npm run build:standalone` 生成无需网络打开的单HTML；`npm run package:local` 生成本地启动包。推荐固定 http://127.0.0.1:8765，静态服务仅绑定本机。不同浏览器／地址的数据分别保存；升级前完整导出，再在新地址恢复。旧目录不覆盖。

根据用户最新要求，以本地交付为先，本PR不合并、不更新gh-pages、不触发线上发布。保留原main与已部署V0.40作为回滚基线；此更改不需要任何数据迁移或重算。未来发布可使用既有检查与Pages流程。
