# 新乐评主义

一个本地优先的私人专辑评分工具。在原有 React / TypeScript / Vite 项目中重构，继续使用 V0.19 的精确评分引擎、558 项风格、33 项中国市场索引和同一个 IndexedDB 数据库。

## 开始使用

```bash
npm ci
npm run dev
```

需要 Node.js 22.12+。测试还需要 Python 3.10+；浏览器测试默认使用 `/usr/bin/chromium`，其他位置可通过 `CHROMIUM_PATH` 指定。

操作流程：搜索专辑或手动添加 → 确认专辑信息与一、二级风格 → 六维半星评分 → 生成评分卡并导出 PNG。首页只呈现搜索和近期记录，备份、历史与诊断放在设置中。

- 每个维度只有五颗星，点击左、右半部选半星或整星，支持触摸与键盘。私人评分不要求评价理由或审核文字。
- 默认 1080×1350（4:5），可选 1080×1440（3:4）或 1080×1080（1:1）。封面和六瓣玫瑰图构成主体；图形长度只取决于星级。短评可不填，最多 200 个 Unicode 字符。
- 中国／其他地区只改变风格排序；所有风格来自统一父子树。音乐人国籍、语言与 Spotify 可售市场都不会改变权重。
- 无法确定歌曲来源时保留草稿和待确认分数，不会猜填来源档位。新创作由用户确认后采用无来源修正；旧歌／混合／旧作重录由简短选择确认冻结政策中的档位，且检查重复计量。界面不提供手调权重。
- 多风格模式只聚合逐曲风格权重，整张专辑仍只有一组六维星级。作词 N/A 与未评分分开，罕见表演 N/A 需要单独确认。

## Spotify

官方 API 集成使用服务端代理，`SPOTIFY_CLIENT_SECRET` 不会进入前端构建。配置方式、托管接口和限制见 [Spotify 接入说明](docs/SPOTIFY.md)。

本次环境没有 Spotify 凭证，且网络策略未开放 Spotify 域名，因此没有验证真实账户调用，也不宣称搜索已经联网接通。未配置时应用会明确提示，并提供可工作的手动添加。浏览器验收中的 Spotify 响应是测试专用夹具，不会内置到用户搜索结果。

Spotify 返回的专辑、艺人、日期、曲目、时长和封面用于填充信息；艺人流派不作为专辑风格，`single` 不自动当作 EP，播放市场不作为音乐创作地区。外部封面经正常 CORS 获取并嵌入导出；如加载受限，使用本地封面上传。Spotify 数据的实际使用权限和导出条款应在正式接入账号前核实。

纯静态 GitHub Pages / 本地单文件没有服务端代理，默认支持本地记录与手动录入；不会在 HTML 或 Vite 公开变量里保存 Client Secret。

## 数据与历史

评分进度自动保存到原有 `nmc-workbench-v1` IndexedDB，未清空或更名。请使用固定浏览器和 origin（协议、域名、端口）读取同一份数据。

- 设置中可导出／导入全量 JSON。相同备份幂等导入；冲突会明确拒绝，不静默覆盖。
- 旧记录的六维、证据、修正、元数据仍保留。新 UI 隐藏审核字段，不删旧字段。仅修改卡片比例、主题或市场排序，不重置原有来源向量。
- 已发表记录及历史快照展示冻结的结果，重新评分创建新记录。新评分卡是私人记录，PNG 导出不表示正式发表或已经核验史料。
- 草稿自动保存最新进度；保存卡片时留存版本快照。浏览器数据需要另行备份，内容不会写回应用 HTML。

## 计算与验证

`src/model/engine.ts` 继续使用 BigInt 有理数和原始数学规则，最后一步 half-up 到两位。原有 `calculate()` 保留严格公开审核语义；私人流程通过共享数学核心的 `calculatePrivate()` 计算，不生成伪造的证据、不伪装通过审核。来源仍使用原五档冻结向量，文化数值修正新记录保持 0，N/A 归一化、5% 下限和毛额预算继续校验。

```bash
npm test
npm run test:reference
npm run build
npm run test:e2e
```

`npm test` 先实际运行 Python 生成对照矩阵，再验证全部 9 条黄金案例和 11,160 种风格／来源／N/A 配置。用户提供的原始模型文件保持不变，存放于 `docs/reference-supplement/` 和 `docs/model-source/`。本次重构任务书与旧版说明存于 `docs/ux-refactor/`。

## 构建与交付

```bash
npm run build               # dist/：标准静态站点
npm run preview             # 预览生产构建
npm run build:standalone    # standalone/新乐评主义.html：单文件
```

生产站点在首次成功缓存后可离线使用本地功能。当前环境禁止浏览器 `file://` 导航，单文件双击方式无法在这里实测；其程序、样式和数据均已内嵌，仍须浏览器允许本地存储。GitHub Pages 的在线版本需要在仓库设置中启用发布分支；运行本地开发服务不等于提供公网网址。

真实 Spotify 账户授权、配额及条款核对仍未完成。现有单文件与静态站点使用手动录入；不会以测试夹具或艺人流派伪装真实的专辑搜索和风格推荐。
